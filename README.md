# LASTZONE — Battle Arena

A mobile-friendly browser battle arena prototype inspired by the battle-royale genre. It uses original branding and simple original canvas artwork.

## Play
Open **index.html** locally or enable GitHub Pages (Settings → Pages → Deploy from branch → main / root).

## Features
- Lobby with 3 selectable fighters and 4 outfit colors.
- Solo battle against 11 bots.
- 12 weapons: AR-15, AK-47, M4A1, MP5, UMP, P90, SCAR-L, AWM, M1014, Desert Eagle, Groza and Vector.
- Health, armor mitigation, ammo, reload, pickups, shrinking safe zone, kills and win/lose screen.
- Mobile joystick and fire/reload/switch controls; keyboard WASD, Space, R, Q.
- PWA manifest and service worker for install/offline shell.

## Notes
This is a playable 2D prototype, not a full 3D online multiplayer game. Bots run locally in the browser. All visuals are original CSS/canvas shapes.
