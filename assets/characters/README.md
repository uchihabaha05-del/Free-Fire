# MASS BATTLE character models

The character picker expects one Godot-importable GLB file per hero in this folder:

- spider_man.glb
- hulk.glb
- thor.glb
- captain_america.glb
- iron_man.glb
- thanos.glb
- doctor_strange.glb
- black_panther.glb
- deadpool.glb
- wolverine.glb

Use rigged, game-ready GLB/glTF models with embedded textures. Keep each model's license and attribution file beside the model. Only add models you have permission to use and redistribute in this project.

Until a matching GLB is present, the game displays a clearly marked temporary placeholder. The placeholder is not an official Marvel design and is not intended to look like the original character.
